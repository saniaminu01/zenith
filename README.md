# Zenith

An AI-powered chat agent built on the XMTP Agent SDK.

Zenith responds to a few slash commands, and uses Claude for AI-generated replies to everything else.

## Commands

| Command   | What it does                          |
| --------- | -------------------------------------- |
| /gm       | Says gm back                           |
| /echo     | Echoes whatever you type after it      |
| /whoami   | Shows your XMTP inbox ID and address   |
| /ping     | Health check - replies "pong"          |
| /help     | Lists all available commands           |

## Setup

npm install
npm run gen:keys
npm run dev
